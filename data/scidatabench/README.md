# SciDataBench

245 scenarios over four scientific data platforms. Each scenario is built from a published paper whose analysis uses only that platform's API, and is decomposed into four phases: knowledge discovery (Phase 1), API-call construction (Phase 2), preprocessing (Phase 3) and research-question answering (Phase 4).

## Contents

| Platform | Folder | Scenarios |
|---|---|---:|
| EPA AQS | `epa/` | 11 |
| GBIF | `gbif/` | 51 |
| NEON | `neon/` | 23 |
| USGS | `usgs/` | 160 |
| **Total** | | **245** |

Each scenario is one JSON file, `<platform>/<scenario>.json`. `papers.csv` lists the source paper of every scenario.

## Scenario fields

| Field | Content |
|---|---|
| `source_doi` | DOI of the paper the scenario is built from |
| `research_question` | The paper's research question |
| `phase_1.user_prompt` | Request for the platform identifiers |
| `phase_1.expected` | Gold identifiers, one list per key of the platform's schema |
| `phase_2.user_prompt` | Request for the data |
| `phase_2.expected` | Gold calls, each with `module`, `function` and `kwargs` |
| `phase_3.user_prompt` | Request for the intermediate quantity |
| `phase_3.expected` | Gold value: a number, or an object or list of numbers |
| `phase_3.unit` | Unit of the gold value |
| `phase_4.user_prompt` | Request for the paper's headline finding |
| `phase_4.expected` | Gold numeric value |
| `phase_4.unit` | Unit of the gold value |
| `phase_4.checkpoint` | The paper's qualitative conclusion and figure reference, where the request also asks for them; recorded, not graded |
