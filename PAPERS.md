# Source Papers

Every scenario in both sets is built from a different published paper whose
analysis uses only one platform's API, so the paper's reported result is the
ground truth. This page lists all 455 papers: 245 behind SciDataBench and 210
behind SciDataBench-Onboard. The same lists are in `data/*/papers.csv`.

- [SciDataBench](#scidatabench) — 245 papers: [EPA AQS](#epa-aqs) (11), [GBIF](#gbif) (51), [NEON](#neon) (23), [USGS Water Data](#usgs-water-data) (160)
- [SciDataBench-Onboard](#scidatabench-onboard) — 210 papers: [American Community Survey](#american-community-survey) (22), [Argo](#argo) (15), [CMIP6](#cmip6) (29), [Ensembl](#ensembl) (30), [iNaturalist](#inaturalist) (16), [Materials Project](#materials-project) (27), [NOAA GHCN](#noaa-ghcn) (25), [OBIS](#obis) (13), [PANGAEA](#pangaea) (16), [USGS Earthquake Catalog](#usgs-earthquake-catalog) (7), [VizieR](#vizier) (10)
